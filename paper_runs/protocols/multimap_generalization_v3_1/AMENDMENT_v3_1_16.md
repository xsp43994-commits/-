# v3.1.16 零回合试训数值边界修订

v3.1.15 的 PPO＋Pointer 试训在第 0 回合、任何梯度更新和算法比较之前停止。根因是一个已被 HiGHS 认证为最优的 validation 场景将数学相等的覆盖率下界和上界以相差约 `3e-17` 的反序浮点数写入；严格的 `lower <= upper` 检查将其误判为无效。

v3.1.16 只在 `1e-12` 的注册数值容差内将该类舍入级反序规范化为有序区间；任何更大的反序、非有限值或超出 `[0, 1]` 的边界仍然被拒绝。该规则不读取任何学习算法、传统算法或试训结果，不改变地图、道路、任务点、预算、奖励、掩码或 MILP 证书。

全部 648 个训练记录、108 个 validation 记录、36 个正式合并基础记录和四个分片记录必须逐字节不变。旧环境封存和零回合失败目录移动到审计归档，随后重新执行全量任务审计、环境封存及三个 600 回合试训模型；35 个正式模型仍不得在 `assess-pilot` 门禁通过前启动。
