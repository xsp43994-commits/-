# 顶刊算法论文图型调研与选择依据

## 1. 调研结论

图型不按“是否漂亮”选择，而按面板要回答的数据问题选择。调研覆盖 Nature、
Nature Machine Intelligence 和 Nature Communications 的算法比较、强化学习、
多指标基准和多目标优化论文，并以 Nature 官方制图规范作为输出约束。

与本研究最相关的顶刊用法如下：

| 数据问题 | 顶刊常用图型 | 本研究采用方式 |
|---|---|---|
| 多算法随机重复的绝对分布 | 箱线图、小提琴图、原始点 | 半小提琴＋箱线＋稀疏场景点 |
| 提议算法相对基线的配对效应 | 森林图、估计图 | Hodges–Lehmann差异＋95% CI森林图 |
| 多任务/多数据集平均排名 | 临界差异图、排名分布 | 临界差异图放补充材料；主文使用排名可接受度热力图 |
| 多指标总体画像 | 标准化热力图、点图 | 固定顺序的分量热力图；不做聚类重排 |
| 超参数、训练过程、规模变化 | 折线图＋置信带 | 节点规模折线＋95%区间带 |
| 两种工况的配对变化 | 哑铃图、斜率图 | `id_test`—压力工况哑铃图 |
| 重尾运行时间 | 对数尺度KDE、ECDF | 对数横轴ECDF＋中位数标记 |
| 多目标冲突与折中 | Pareto散点及前沿 | 任务效能—资源效率Pareto图 |
| 类别构成 | 100%堆叠条形图 | 终止原因构成，放主图辅助面板或补充材料 |
| 权重空间内冠军变化 | 三元决策图、排名概率图 | 三元权重冠军区域＋排名可接受度热力图 |
| 路径规划结果 | 俯视路径、剖面、累计曲线 | 俯视路线＋高度剖面；不使用遮挡严重的3D宫格 |

## 3. 明确不采用的图型

- 不使用雷达面积作为综合排名：面积会放大轴顺序和归一化造成的视觉差异。
- 不使用饼图：算法数量和终止类别较多时难以精确比较。
- 不使用只有均值的柱状图：会隐藏100个场景的分布、配对结构和长尾。
- 不使用3D柱状图、3D曲面排名图或透视路径宫格：遮挡且不能增加统计信息。
- 不使用彩虹色热力图：采用感知均匀、色盲安全的顺序或发散色图。
- 不重复用不同图型展示同一份数据；每个面板必须补充新的证据维度。

## 4. 图型合同

### 主图1：综合最优算法证据链

- 核心结论：PPO＋Pointer是否在固定综合评价和权重扰动下稳健领先。
- 图形原型：非对称定量证据网格。
- a：综合分半小提琴＋箱线＋稀疏场景点。
- b：PPO＋Pointer相对8种主方法的配对差异森林图。
- c：算法×名次的SMAA排名可接受度热力图。
- d：`E/R/C`三元权重空间的冠军区域图。
- 主证据：b；稳健性证据：c、d；绝对分布：a。

### 主图2：综合分组成与工程权衡

- 核心结论：总体优势来自任务效能、资源效率和在线效率中的哪些部分。
- 图形原型：定量网格。
- a：`S/E/R/C`分量点阵热力图，算法顺序固定、不聚类。
- b：安全率与四类违规率的点—区间图。
- c：三项预算利用率的并列Cleveland点图，仅使用安全路线。
- d：规划时间对数尺度ECDF。
- e：任务效能—资源效率Pareto散点及非支配前沿。

### 主图3：四项消融

- 核心结论：完整方法相对消融的损失大小和损失来源。
- 图形原型：配对效应网格。
- a：综合分配对效应森林图。
- b：`E/R/C`分量哑铃图。
- c：高/中/低优先级覆盖差异点图。
- d：终止原因变化热力图；`no_return_reserve`标为仿真安全消融。

### 主图4：压力与规模稳健性

- 核心结论：优势是否在困难工况和节点规模变化时保持。
- 图形原型：条件变化网格。
- a：`id_test`—压力工况综合分哑铃图。
- b：`id_test`—压力工况安全率哑铃图。
- c：8/12/20/24节点的综合分折线＋95%区间带。
- d：节点规模—安全加权覆盖率折线＋95%区间带。
- e：节点规模—规划时间对数折线。

### 主图5：代表路线解释

- 核心结论：统计优势如何对应到实际访问顺序、优先级覆盖和安全返航。
- 图形原型：非对称混合模态。
- a：统一坐标的俯视路径图。
- b：高度—累计航程剖面。
- c：能量、距离和时间预算累计利用曲线。
- d：关键指标小型点表，不使用雷达图。

## 5. 出版与审稿风险控制

- 图宽固定为183 mm，高度不超过170 mm；面板正文5–7 pt，面板字母8 pt粗体。
- 所有图由Python/Matplotlib独占生成，SVG文字保持可编辑，PDF使用TrueType 42。
- PPO＋Pointer固定深蓝；算法家族使用同色系低饱和颜色；红/绿只表达有方向的变化。
- 所有区间、中心量、`n`、检验和校正方法写入图注与Source Data。
- 主文图不按结果重新排序，避免通过排序或配色制造视觉冠军。

## 6. 补充图S1：学习与收敛行为

35个正式训练目录均保存3000回合回报以及按更新记录的外部固定验证集指标，因此增加一张训练过程证据图：

- 核心三模型的回合回报采用“五训练种子中位数＋四分位带”，固定100回合滚动中位数；每个模型使用一种固定颜色。
- 七个学习变体统一比较外部固定validation的`weighted_coverage`与`return_rate`，仍采用五种子中位数和四分位带。
- `no_resource_shaping`改变了奖励定义，故七个变体不得用原始reward的绝对高低判优。
- 收敛曲线只回答优化过程、稳定性与训练预算是否充分；最终算法优劣只由冻结`id_test`决定。
