A B S T R A C T
Performing evasive maneuvers with highly automated vehicles is a challenging task. The algorithm must
fulfill safety constraints and complete the task while keeping the car in a controllable state. Furthermore,
considering all aspects of vehicle dynamics, the path generation problem is numerically complex. Hence its
classical solutions can hardly meet real-time requirements. On the other hand, single reinforcement learning
based approaches only could handle this problem as a simple driving task and would not provide feasibility
information on the whole task’s horizon. Therefore, this paper presents a hierarchical method for obstacle
avoidance of an automated vehicle to overcome this issue, where the geometric path generation is provided by
a single-step continuous Reinforcement Learning agent, while a model-predictive controller deals with lateral
control to perform a double lane change maneuver. As the agent plays the optimization role in this architecture,
it is trained in various scenarios to provide the necessary parameters for a geometric path generator in a one-
step neural network output. During the training, the controller that follows the track evaluates the feasibility
of the generated path whose performance metrics provide feedback to the agent so it can further improve its
performance. The framework can train an agent for a given problem with various parameters. As a use case,
it is presented as a static obstacle avoidance maneuver. the proposed framework was tested on an automotive
proving ground with the geometric constraints of the ISO-3888-2 test. The results proved its real-time capability
and performance compared to human drivers’ abilities.
1. Introduction
Path planning and safe maneuvering are essential in designing
Advanced Driver Assistance Systems (ADAS) and are fundamental prob-
lems for developing automated vehicle functions. These problems have
multiple significant requirements. One is the feasibility, i.e., the gen-
erated path or trajectory needs to consider the vehicle’s parameters
and dynamics to let the actual controller follow it with as slight a
deviation as possible. The other aspect is computational performance,
or in other words, the real-time capability of the method. Considering
every nonlinearity in the vehicle model and providing an optimized
solution for the planning horizon is a complex task, leading to increased
numerical resources used for solution generation. Considering all holo-
nomic and differential constraints, the optimal solution for finding a
path is PSPACE-hard, which naturally remains with the inclusion of a
speed profile and dynamic constraints according to Reif (1979). This
practically means that one cannot find a proven optimal solution for the

are built on a hierarchical structure where the layers interact. On the
top level, route planning generates a high-level route between the
vehicle’s position and destination. The behavioral layer defines a local
motion specification based on the route, surrounding topology, and
obstacles. These are strategic short-term decisions, like lane-keeping
or changing, car-following, object avoidance, etc. The motion planning
layer generates a reference path or trajectory for the given maneuver,
and finally, the local feedback control layer drives the vehicle along this
predefined path. Naturally, the layers must interact and redesign the

A highly automated vehicle must drive the most optimal route when
performing a tricky maneuver, such as a double lane change. One can
specify several optimization criteria, from comfort to safety (Ciuffo
et al., 2021). From all of them, minimizing jerk and lateral acceleration
serves both purposes (Hegedűs et al., 2020). Our current research aims
to create an experimental method to design the optimal route for a
double lane change in real time. Though the trained algorithm can
solve the task under a wide range of conditions, a field test is presented
with the parameters of the so-called ‘‘Moose-test’’, a double lane-
change obstacle avoidance maneuvering setup defined in the standard
ISO-3888-2 (International Organization for Standardization (ISO 3888-
2:2011), 2011) shown by Fig. 1. During this test, the vehicle accelerates
to a defined velocity till the entry point and needs to pass through three
straight sections with a released throttle.
As mentioned above, the path is generated by an agent, and an
MPC controller performs its following. During experimental tests, two
key factors are essential for accurate path tracking: the knowledge of
a certain path length ahead of the vehicle and the consideration of the
vehicle dynamics in the control law. The Model Predictive Controller
(MPC) meets both demands. The first key factor is satisfied by determin-
ing the control input by executing an optimization process based on the
reference states and the predicted vehicle states. The second constituent
is assured by calculating the predicted states based on a simplified
vehicle model. Furthermore, the MPC can handle constraints applied as
limits for the steering actuator intervention, hence the steering system
dynamics have been identified to achieve accurate and reliable path
tracking.
1.1. Related work
Path and trajectory planning for highly automated vehicle functions
has a broad literature with multiple approaches, best summarized in
the following review papers (Paden et al., 2016; Claussmann et al.,
2019; González et al., 2015; Ferencz and Zöldy, 2024). The curve,
or set of waypoints the vehicle needs to follow, is called a path.
If the path is also parametrized by time or velocity, it is called a
trajectory. The problem assumes a robot motion model, which can be
either holonomic or nonholonomic, kinematic or dynamic, linear or
nonlinear, probabilistic or deterministic, etc. Furthermore, it needs to
define a path between two endpoints, with given initial conditions,
considering static or dynamic obstacles that the robot must avoid.
Path planning is widely studied for several types of mobile robots, like
underwater vehicles (Ma et al., 2019), ships (Li et al., 2020), Unmanned
Aerial Vehicles (Huang and Fei, 2018) or even robot arms (Kunz
et al., 2010), all having different dynamics and degrees of freedom.
However, as mentioned in the introduction, the high complexity of
the complete solution leads to the research of several methods that
either neglect dynamic feasibility or aim for a suboptimal solution,
using geometrical approaches, heuristics, optimal control, or nonlinear
programming. Heuristic or search-based methods usually adopt the A*
algorithm and customize it to achieve faster or more feasible paths.
For example, in Ferguson et al. (2008), the authors use resampling,
while in Likhachev et al. (2005), adaptive refining is proposed. Since
the methods hardly conform to the nonholonomic kinematics of the
Ackermann steering, some researchers aim to extend the state space
to be continuous (Montemerlo et al., 2008). Another search-based
approach is the Rapidly-exploring Random Tree (RRT), which considers
dynamics and finds a solution in a non-convex space. However, it
does not guarantee optimality (Kuwata et al., 2009; Pepy et al., 2006).
The fully constrained optimization problem can be dealt with by any
solver, though it raises the question of real-timeliness (Lin et al., 2019).
One possible approach is to use machine learning to train a neural
network for the solutions of many optimization results and use it as
an immediate solution or an initial guess for the solver (Hegedüs et al.,
2019), which can work for simple setups. However, for more complex
scenarios, training dataset generation is also a challenging task to
cover the entire state space. Another approach is to use Reinforcement
Learning (RL), where the agent interacts with its environment based
on trial-and-error and experiences and develops the optimal behavior
through the performance metrics, called rewards (Sutton and Barto,
2018). RL is based on the Markov Decision Process, where an agent
receives state information from the environment, based on which it
generates its action, which alters the environment state by a state
transfer function. The environment also provides a so-called reward for
each step or at the end of an episode, which is technically an objective
function for the task. The agent aims to maximize its reward and learns
from the experiences gained from previous episodes. These methods
generally utilize end-to-end solutions in the literature, meaning the
agent acts with steering and acceleration commands. The trajectory
planning is hidden somewhere in the knowledge acquired through the
training. As the agent can deal with unstructured data, many sensor
models can be used, such as grid-based (Folkers et al., 2019), beam
sensors (Lee et al., 2017), camera (Wolf et al., 2017) or ground truth
position information (Xia et al., 2016). The other end of the RL-based
research focuses on strategic decisions, defining high-level actions,
and letting an underlying controller perform the task, which is out of
the scope of the paper. Only a few solutions exist in the literature,
where the actual path planning is made with RL (Ronecker and Zhu,
2019; Fehér et al., 2020b). One can find a survey on RL-based motion
planning in Aradi (2020), and on one of its subsets, imitation learning
in Ly and Akhloufi (2020).
Multiple papers focus on hierarchical or multilayer solutions for the
combined motion planning problem for different scenarios. The method
proposed in Chai et al. (2022b) applies a double-layer structure, where
an intelligent optimization method is used in the outer layer such
that the main inner optimization routine can be boosted by starting
at a better reference solution. The authors demonstrate the approach’s
effectiveness in a multi-phase overtaking maneuver. To overcome the
computational problems of classical methods, the authors of Chai et al.
(2022a) utilize a recurrent deep neural network (RDNN) for planning
optimal parking maneuver trajectories and an adaptive learning NN-
based (ALNN) control scheme for robust trajectory tracking. They also

Regarding the trajectory following, three types of MPCs are used
for path tracking: the linear parameter-varying (LPV-MPC) (Kianfar
et al., 2013; Cao and Zoldy, 2021) the linear time-varying (LTV-
MPC) (Falcone et al., 2007), , and the nonlinear (NLMPC) (Borrelli
et al., 2005) MPCs. Complexity, performance, accuracy, and the compu-
tational requirement of the controllers are increasing, respectively. The
LPV-MPC applies a linear system model for state prediction, which does
not change over time and has the lowest computational cost. However,
it is also the least suitable for handling the nonlinear behavior of the
controlled system. In the LTV-MPC, the nonlinear equations describing
the system’s dynamics are linearized at every timestep in the system’s
current state. The NLMPC calculates the evolution matrices of the sys-
tem without linearization generating a nonlinear optimization problem.
Hence this is the computationally most expensive method, which may
limit the application of this method on real-time systems, as discussed
in Falcone et al. (2007).
1.2. Contributions of the paper
The paper presents a reinforcement learning-based path planning
solution to determine the path of an emergency double lane change ma-
neuver. The path is made up of polynomial segments whose coefficients
are determined by a Twin Delayed Deep Deterministic Policy Gradient
(TD3) learning agent. The planner was evaluated by field tests using a
moose-test defined by ISO 3888-2. The article details the experimental
setup and the MPC controller used for path following. The paper also
presents field test measurements of a solution made using a previously
published (Fehér et al., 2020a), clothoid-based double lane change path
planner. A brief video abstract can be found following the link in the
footnote.1
Section 2 introduces the RL training method. It describes the train-
ing environment, the TD3 agent, the dynamic vehicle model briefly,
and solution to generate the polynomial path. In addition, the net-
work architecture, the state, action-space, and reward function are
also presented. The following sections are focused on field tests. Sec-
tion 3 presents the experimental setup. Afterward, Section 4 details the
MPC controller used on the tests. Finally, Section 5 provides informa-

2. Proposed method and training framework
The task outlined in the previous chapter is solved by combining
a reinforcement learning agent and geometrical path planning. As
Fig. 2 shows, a learning agent has been placed in a simulation training
environment where it needs to learn to act correctly. The reward
function determines the correct actions. An episode consists of one step,
reducing the task’s complexity. In each episode, the agent gets the state-
space parameters defining the double lane-changing mission. These
parameters are the width, length, and position of the lanes the vehicle
must follow without error. Based on this, the agent predicts coefficients
(action-space) from which a path is generated. The path is a cubic spline
constructed from piecewise third-order polynomials. According to the
reviews mentioned earlier (Claussmann et al., 2019; González et al.,
2015), for vehicle path planning, polynomial degrees of the splines
range from quadratic to quintic, though the most common approaches
use cubic splines. Second degree polynomials result in high jerks, while
higher grades can be smoother, though computationally more complex.
The reward function is responsible for evaluating the goodness of the
path. As this motion planning method would not contain feedback,
the training loop is closed by an evaluation phase, where a closed-
loop MPC controller (see Section 4) drives a dynamic vehicle model
along the track while evaluating feasibility. An essential consideration
in developing the learning environment is that its outcome should be
tested in an actual vehicle. Therefore, it also performs a one-step path
planning and follows this path with the closed-loop MPC based on
sensor data.
The motivation for applying the proposed combination in a hierar-
chical solution comes from the fact that the classical methods suffer

2.1. Reinforcement learning environment
2.1.1. Agent
Twin-Delayed Deep Deterministic Policy Gradient (TD3) (Fujimoto
et al., 2018) was chosen as the agent, which is the successor to Deep
Deterministic Policy Gradient (DDPG) (Lillicrap et al., 2015). DDPG is
a robust algorithm for continuous action and state-space problems, so
it can also efficiently solve automated vehicle control tasks in Fehér
et al. (2020a) and Fehér et al. (2019). However, for more complex tasks
with large action space, DDPG is very sensitive to hyperparameters
(e.g., learning rate, Ornstein–Uhlenbeck noise process parameters, etc.),
which can cause convergence to a local maximum.
The DDPG algorithm was presented in detail in our previous arti-
cle (Fehér et al., 2020a). From now on, the differences are in focus.
The better performance of the TD3 compared to the DDPG is provided
by three enhancements. The first is the delayed update of the actor-
network. However, in actor-critic solutions, the overestimation can
cause divergence. TD3 solves this by updating the weights of the actor-
network only every second step to reduce the error, resulting in a more
stable and efficient training process. Secondly, the algorithm uses two
critic networks, with a clipped double Q learning method (Hasselt,
2010). The smaller of the two bad critic networks is selected. This
method helps to eliminate underestimation bias. The third method is
action noise regularization, which can smooth the target policy. A
clipped noise is added to the selected action, which favors higher values
for the action, making it more robust.
2.1.2. Network architecture and hyperparameters
To understand the TD3 algorithm, Fig. 3 shows the training process.
An experience replay buffer, two actors (target, main), and four critics
(main 1, main 2, target 1, and target 2) networks are created to
initialize the agent. The algorithm samples from the replay buffer
during the training process, where s is the current state, s’ is the next
state after the action, and r is the reward value. At the beginning of the
training, the target network predicts from the s’ (next state), a’ (next
action) to which noise is applied and clamps it in a range of values
supported by the environment (according to the Table 1). The critic
target networks use the pairs s’, a’ to predict 𝑄𝑡1 and 𝑄𝑡2 values. The
minimum of these two Q-values represents the approximated value of
the next state. The Bellman equation gives the final target value 𝑄𝑡,
where 𝛾 is the discount factor. The two main critic networks predict a
Q value (𝑄1, 𝑄2) based on (a, s). After that, the loss can be calculated.
The critic loss is backpropagated to update the parameters of the two
critic models with an SGD optimizer. The actor main can be updated
by performing gradient ascent. In every second iteration, the weights of
the actor and critic targets are updated by Polyak averaging, meaning
the target parameters are updated with a ratio of the main network,
which provides smoothing in the training process.

2.1.5. Reward function
The reward function implemented for this training differs from the
commonly used solutions. Usually, an episode consists of several steps,
and a reward value is calculated after each step. The agent receives
a reward value after each episode in a one-step case. This one-step
training reduces the complexity of the learning task, so it is possible
to use a more resource-intensive reward function. The training uses
a nonlinear single-track vehicle model containing a dynamic wheel
model introduced in Hegedüs et al. (2017), which gives a good trade-off
between accuracy and computational complexity. The vehicle model
is driven along the track with a lateral MPC controller. The reward
is calculated from the performance of the whole loop. A PI controller
is responsible for accelerating the vehicle to speed 𝑣0, and during the
execution of the maneuver, there is no longitudinal control from the
torque release point. According to the reward function, the following
events cause the termination of an episode. The agent receives a
negative reward (penalty) in these cases.
• Longitudinal rear or front slip greater than 0.1
• Lateral rear or front slip greater than 0.2 radian
• The euclidean distance between vehicle CoG and the nearest point
of the path (distance error) greater than 1 meter
• The angle difference between at closest point of the path and
vehicle (angle error) greater than 20 degree
• The vehicle hit a cone

3. Vehicle and instrumentation setup
As a vehicle platform for the functional field tests, a series pro-
duction coupé car (BMW M2) was used after suitable modification to
enable self-driving.
As shown in Fig. 7, the architecture uses a dSpace MicroAutoBox
II 1401 for motion controller implementation, data acquisition, and
actuator control. An Nvidia Jetson AGX Xavier development board
calculates the AI algorithms to utilize GPU performance. The control
loop runs with a 1 ms sample time thanks to the rapid prototyping
system.
To enable steering control, a steering robot was installed in the place
of the original steering wheel. It was used in angle control mode and
communicated via CAN bus with the MicroAutoBox.
For the longitudinal motion control of the car, the accelerator pedal
was removed, and the MicroAutoBox emulated its signal. The vehicle’s
velocity is controlled separately from the lateral motion control by a
PI cruise controller to ensure the accurate and reproducible entering
speed of the accident avoidance track.
As also shown in Fig. 7, for the self-localization of the vehicle, a
GNSS system was used with GSM RTK correction and dual antennas.
All states (including sideslip angle, yaw rate, longitudinal velocity, etc.)
are calculated from the measured high-frequency position and heading
signals.
Due to safety reasons, signals from the vehicle CAN were received
by a non-intrusive contactless sensor and were converted to FMS-
Standard messages by a special CAN Gateway (Inventure Automotive
FMS Gateway). The installation of the instrumentation and the steering
robot in the car interior is depicted in Fig. 8.

according to the control objective in the MPC controller. Tracking per-

5. Results
To better compare the methods and the role of the two concepts in
the algorithm’s success, an ablation experiment was conducted using
the combination of the polynomial- and clothoid-based path generation
and the DDPG and TD3 agents. Also, for a wider comparison, Soft Actor-
Critic (SAC) (Haarnoja et al., 2018) and Proximal Policy Optimization
(PPO) agents (Schulman et al., 2017) were also included.
Each training lasted for 150k episodes, which lasted approximately
twenty hours for each training on a medium-performance PC con-
figuration (i7-7700 with GTX 1080 Ti). As shown by Fig. 11, the
polynomial-based path planner can perform better than the clothoid-
based on this task. However, the DDPG agent was unable to train itself
for the polynomial representation, even with several hyperparameters,
of which one was shown in the figure. Acceptable reward regarding the
clothoid representation is only achieved by the PPO method. Though
the PPO-polynomial reached the performance of the TD3-polynomial
solution, its training lasted for 500K episodes. SAC-polynomial almost
reached the same performance as the TD3. The answer to why the
clothoid-based planner is inferior in performance to the polynomial
based on comes from the fact that it has a much higher predefined
jerk in the mid-section because of the clothoid-straight curve transition,
resulting in higher lateral acceleration and the need for stabilization
from the side of the controller.

fulfill the primary goal, and the vehicle cannot keep the geometric
constraints. Naturally, in the more challenging scenarios, the algorithm
sacrifices the lateral acceleration and jerk to pass the test, resulting in
higher slip values.
The proposed method is compared to a baseline path planning
method in simulation. As nonholonomic variants of the A* and RRT
algorithms could not provide close-to-optimal solutions in a reasonable
time for the given problem, the comparison is carried out with an Adap-
tive MPC-based path planner. The planner uses a nonlinear kinematic
model, where the dynamic constraints are considered by optimizing
to steering angle rate of change and lateral acceleration. The same
controller drove the generated path as for the proposed method, and
the traveled path and lateral acceleration value comparison is shown
in Fig. 12.
The performance of the proposed method regarding lateral accel-
eration is the same as the MPC baseline, though their peaks appear at
different points. The proposed planner reaches peak lateral acceleration
(and hence, sideslip) at the beginning of the maneuver, while the MPC-
based one reaches it when turning back. Though their performance in
this way is the same, the MPC needs approximately 1 s of planning
time to deal with obstacle avoidance, while the trained agent predicts
the parameters in 1 ms and generates the path in 10 ms.
The results were also evaluated with field tests. The measures are
performed with the moose test parameter set according to ISO3888-
2. The tests were carried out at the ZalaZONE Proving Ground in
Zalaegerszeg (Szalay et al., 2018, 2019; Szalay, 2021). In the middle
of the dynamic platform, which is an ultra-flat asphalt surface with a
diameter of 300 m. The cones were positioned using RTK GPS. The
starting position of the vehicle was also determined by fixing a 60 m
long straight route for acceleration and a safe distance to braking at
the end of the test. The DSC (Dynamic Stability Control for BMW
vehicles; can be considered as ESP system) was switched off during the
measurements because the effect of the DSC was also neglected in the
training environment.

fewer lateral accelerations. Accordingly, less sideslip means more stable
controller performance because there is more reserve about the sideslip
to reach the end of the linear region of the tire characteristics. Overall,
the smoother curvatures of the polynomial path result in less lateral
acceleration and fewer sideslip angles which provides a more stable,
safer, and more comfortable ride.
6. Conclusion
The article presents a real-time geometric path planning agent
trained with Reinforcement Learning for performing a double lane
change maneuver. The field test showed the success of domain adap-
tation, as the trained agent successfully performed the test in all cases.
Furthermore, it outperformed an earlier clothoid-based designer and
human drivers also.
Naturally, there are impossible scenarios where the motion planning
task has no solution based on the dynamic capabilities of the vehicle
and the geometric parameters of the expected maneuver. In this or any
Fig. 16. MPC controller errors, steering wheel and sideslip angles of same initial speed
of successful ISO 3888-2 experiments in simulation.
feasible case, one must have information about the feasibility of the
designed path for safety reasons. The designed path can be evaluated
in two ways. First, both DDPG and TD3 agents consist of an actor
and a critic network from which the actor provides the action, which
gives the path parameters, while the critic network predicts the Q value
of this action. This value estimates the expected reward, which holds
information on the feasibility of the maneuver. The other possibility
is the model-based verification of the result, where the designed path
is evaluated with simulation. When resulting in a detected unfeasi-
ble path, this motion planning layer should interact with the upper
behavioral layer to choose another strategy.
The benefit of using a hierarchical approach compared to the com-
mon end-to-end RL approaches is that the feasibility of the maneuver
increases, which the agent’s value function can also predict. On the
other hand, it also serves as a drawback since this solution needs a
prototype maneuver, e.g., a predefined path generator for a particular
type of maneuver (the double lane change in our case). Though the
provided structure can be trained for various other path generators,
giving a maneuver pool from which the upper behavioral motion
planning layer could choose the most appropriate one, which could
be an interesting future research aim. The presented design works on
a static obstacle avoidance problem. However, as the designed agent
can act as a one-step optimizer for a path planning problem on a given
horizon, it can be used as part of a nonlinear MPC planner, which insists
